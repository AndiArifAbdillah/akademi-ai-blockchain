# 🚀 Cara Deploy ke Netlify Drop (Gratis, ±2 Menit)

Platform ini situs statis, jadi deploy-nya sangat mudah — tinggal seret, langsung online.

---

## Langkah-langkah

### 1. Buka Netlify Drop
Buka browser ke: **https://app.netlify.com/drop**

### 2. (Disarankan) Buat akun gratis dulu
- Klik **Sign up** → daftar gratis (bisa pakai akun Google/GitHub/email).
- **Kenapa?** Tanpa akun, situs hanya bertahan beberapa jam (sementara). Dengan akun gratis, situs **permanen** dan punya URL tetap.

### 3. Seret file ke Netlify
Seret salah satu ini ke kotak bertuliskan *"Drag and drop your site output folder here"*:
- **File `akademi-ai-blockchain-deploy.zip`** (ada di folder `D:\kuliah\`), **atau**
- **Folder** `Platform belajar AI & Blockchain` itu sendiri.

### 4. Tunggu beberapa detik
Netlify akan mengunggah dan langsung memberi link, contohnya:
```
https://nama-acak-123.netlify.app
```

### 5. Selesai! 🎉
Klik link tersebut → platform Anda sudah online dan bisa dibagikan ke siapa saja (HP maupun komputer).

---

## Setelah Online (Opsional)

- **Ganti nama situs** agar lebih rapi:
  Site configuration → **Change site name** → mis. `akademi-ai-blockchain` →
  link jadi `https://akademi-ai-blockchain.netlify.app`

- **Memperbarui materi nanti:**
  Setiap kali Anda mengubah pelajaran/menambah materi, cukup **seret ulang** folder/zip yang baru ke situs yang sama (menu **Deploys** → drag & drop), atau buat zip baru.

---

## Catatan
- ✅ Kemajuan belajar pengunjung (Lanjutkan Belajar, kuis, backup) tetap berfungsi — disimpan di browser masing-masing.
- 📁 Folder `.claude/` tidak ikut di file zip (memang tidak diperlukan untuk situs).
- 🌐 Setelah online, situs bersifat **publik** — siapa pun dengan link bisa membukanya.

## Alternatif lain (kalau mau)
- **GitHub Pages** — gratis, butuh akun GitHub.
- **Vercel** / **Cloudflare Pages** — gratis, cara mirip Netlify.

Tinggal beri tahu saya kalau mau dibantu salah satu cara di atas. 🙂
